# ergane-test

A greenfield repository managed by [Ergane](https://github.com/bryantharpeorg/ergane),
an agentic software factory: specs are compiled into a work graph, dispatched to
headless coding agents through a LiteLLM gateway that mints one model-constrained
virtual key per attempt, then verified and landed through a merge queue.

The gates this repo is judged against are declared in `ergane.yaml`.
